# QA Portfolio — Ramón Beltrán

> **QA Tester Jr. | Manual + Automation + Performance**

Portfolio de pruebas para demostrar habilidades en testing manual, automatización y performance testing.

## 🎯 Stack Técnico

- **Manual Testing:** Test cases, Bug reports, Matriz de trazabilidad
- **Automatización:** Playwright, Python, Postman, Newman
- **Performance:** k6, Reportes automatizados
- **CI/CD:** GitHub Actions, n8n

## 📁 Estructura

```
01-manual/        → Test cases, Bug reports, Test plans
02-automation/    → Playwright, Postman, Newman
03-performance/   → k6 scripts, Reportes
04-ci-cd/         → Workflows de GitHub Actions
```
